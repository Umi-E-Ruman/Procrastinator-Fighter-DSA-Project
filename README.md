# 🛡️ Procrastinator Fighter

## Introduction

Procrastinator Fighter is a command-line task manager built in C++ that fights procrastination using real Data Structures and Algorithms.

Each feature is powered by a different DSA — from arrays to graphs. This project is my hands-on journey to apply theory into a working, useful tool.

## Completed Features
- ✅ Add a task (stored in an array)
- ✅ View all tasks

## Planned Features (with DSA)
- 🔄 Complete task + Undo (Stack)
- ⏳ Focus mode timer (Queue)
- 🔁 High-priority rotation (Circular Linked List)
- 📊 Task dependencies (Graph)
- 🔍 Quick search (Binary Search on sorted array)
- 📅 Sort by deadline (Merge / Bubble / Selection Sort)
- 📈 Productivity report (Binary Tree)

## How to Run
1. Compile: `g++ ProcrastinatorFighter.cpp -o fighter`
2. Run: `./fighter` (Linux/Mac) or `fighter.exe` (Windows)
3. Use number keys from the menu.

## Status
Project is actively in development. Next feature: Complete task with undo (Stack).
